SIGEVET es el proyecto final de Bases de Datos 1 desarrollado en equipo para una red ficticia de clínicas veterinarias llamada Huella Sana. La propuesta reúne la información de clientes, mascotas, historias clínicas, citas, consultas, medicamentos, inventario y facturación.

## Mi participación y el trabajo en equipo

En la documentación del repositorio mi rol aparece como **analista y modelador de datos**. El proyecto fue realizado con Juan David Polo Herrera, Juan Miguel Ramos Sevilla y Sergio Alejandro Parra Rivera; cada integrante tuvo responsabilidades distintas dentro del equipo.

## Del modelo a la aplicación

El repositorio incluye modelos entidad–relación en distintas notaciones, un modelo relacional, documentación y scripts de la base de datos. La implementación usa MySQL, una API en Java con Spring Boot y una interfaz web en Angular.

La relación entre modelos, tablas y consultas permite ver cómo las reglas del problema pasan del diseño a una estructura que una aplicación puede utilizar. El caso también reúne normalización y ejercicios de álgebra relacional.
