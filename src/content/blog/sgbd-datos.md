Una base de datos es una colección organizada de datos. Un sistema gestor de bases de datos (SGBD) es el software que permite definir, consultar y administrar esa colección. MySQL, PostgreSQL y Oracle Database son ejemplos de gestores.

## ¿Qué aporta un gestor?

Un SGBD ofrece mecanismos para consultar y actualizar información, controlar acceso, mantener restricciones y gestionar transacciones. Las funciones concretas dependen del producto y de cómo esté configurado.

Por ejemplo, una universidad puede guardar estudiantes y asignaturas en una base de datos, mientras el gestor administra las consultas y las reglas que conectan ambas tablas.

## Idea para recordar

**La base de datos contiene la información; el SGBD proporciona herramientas para gestionarla.** Diseñar bien los datos sigue siendo necesario aunque se utilice un gestor completo.
